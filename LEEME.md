# Mi pequeño Windows 98 · PWA

Un escritorio retro que funciona, independiente de Atlas de las Canciones. Inspirado en las interfaces de los años noventa; no es Windows ni está afiliado a Microsoft.

## Programas incluidos

- Bloc de notas: varios documentos, edición, renombrar, guardado automático y papelera recuperable.
- Calculadora: aritmética, porcentaje y soporte de teclado.
- Buscaminas: tres niveles, primer clic seguro, banderas, pulsación larga en móvil y récords.
- Paint 98: lienzo de pixel art, pincel, goma transparente, bote de pintura, guardado en Mis documentos y exportación PNG con transparencia.
- Snake: clásico arcade jugable con teclado o botones táctiles.
- Juego de parejas: memoria con puntuaciones.
- Agenda: tareas y fechas, marcar completadas.
- MS-DOS: una consola divertida con comandos `AYUDA`, `DIR`, `SUERTE`, `ASCII` y otros.
- Mi PC: acceso a tus notas y dibujos guardados.
- Panel de control: cinco fondos, sonidos y copias de seguridad.

## Instalar desde Windows e iPhone

1. Descomprime el ZIP. Puedes abrir `index.html` en el PC para explorarlo; para instalarlo y disponer del modo offline, publícalo en HTTPS.
2. Crea un repositorio de GitHub nuevo (por ejemplo `mi-pequeno-windows98`). Sube **el contenido de la carpeta**, no el ZIP.
3. En **Settings → Pages**, elige **Deploy from a branch**, `main` y `/(root)` y guarda. Usa la dirección HTTPS resultante.
4. iPhone: abre la dirección en Safari → Compartir → **Añadir a pantalla de inicio**. Windows: abre en Edge o Chrome y selecciona instalar aplicación.

## Guardado y privacidad

Los documentos, dibujos, tareas y ajustes se guardan **en el almacenamiento de ese navegador**. No están sincronizados entre dispositivos. En **Panel de control** usa **Exportar** para crear un JSON de seguridad y **Importar** para restaurarlo en otro dispositivo. Ten en cuenta que limpiar datos del sitio o desinstalar la PWA puede borrar el contenido local.

No exige registro, ni cuenta de Apple, ni Mac, ni pago. Para publicarlo en GitHub Pages puedes utilizar una cuenta gratuita de GitHub. No usa analíticas ni descarga datos de terceros.
